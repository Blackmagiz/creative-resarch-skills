# Plan Mode Protocol

## เมื่อไหร่ใช้ Plan Mode

ใช้เมื่อผู้ใช้:
- มีแนวคิดแต่ยังไม่มี RQ ที่ชัดเจน
- ยังไม่มี literature review สมบูรณ์
- ยังไม่มีข้อมูล / ผลงาน / analysis ครบ
- ต้องการ roadmap ก่อนเริ่มเขียนจริง

**สัญญาณ**: "ฉันอยากเขียนเกี่ยวกับ X แต่ยังไม่รู้จะเริ่มยังไง"

---

## Plan Mode Output

### 1. Research Readiness Assessment

ตรวจว่าผู้ใช้มีอะไรครบแล้วบ้าง:

| Component | มีแล้ว | ยังขาด | แหล่งที่ควรใช้ |
|-----------|-------|--------|--------------|
| Research Question | ✅/❌ | | arts-deep-research → Socratic mode |
| Literature Review | ✅/❌ | | arts-deep-research → full mode |
| Theoretical Framework | ✅/❌ | | arts-deep-research → theory search |
| Data / Artworks / Analysis | ✅/❌ | | visual-analysis / practice-based-research |
| Methodology | ✅/❌ | | practice-based-research |
| Target Journal | ✅/❌ | | arts-paper-reviewer → pre-submission |

### 2. Research Plan Document

```markdown
# Research Plan

## Working Title
[tentative title — จะปรับเมื่อเขียนเสร็จ]

## Research Question (draft)
[RQ ที่มีอยู่ หรือ placeholder ถ้ายังไม่มี]
→ ถ้ายังไม่ชัด: แนะนำใช้ arts-deep-research → Socratic mode ก่อน

## Objectives
1. [Objective 1]
2. [Objective 2]
3. [Objective 3]

## Intended Contribution
[งานนี้จะ contribute อะไรใหม่ให้สาขา?]

## Target Venue
- Journal: [ชื่อวารสาร]
- Tier: [TCI / Scopus Q1-Q4]
- Submission deadline: [ถ้ามี]
- Format requirements: [word limit, citation style, etc.]

## Paper Structure (tentative)
[เลือก A/B/C/D + brief outline]

## Resources Available
- Literature: [สถานะ — ครบ / บาง / ยังไม่ได้ค้น]
- Data / Artworks: [สถานะ]
- Analysis: [สถานะ]
- Collaboration: [solo / with co-authors]
```

### 3. Writing Timeline

```markdown
# Writing Timeline

**Total duration**: [X weeks]
**Target submission**: [date]

| Week | Focus | Deliverable | Skills to use |
|------|-------|-------------|---------------|
| 1-2 | Literature review | Literature Matrix | arts-deep-research → full |
| 3 | Theoretical framework | Framework summary | arts-deep-research |
| 4 | Outline + RQ finalization | Paper Plan Card | arts-paper-writer → outline |
| 5-6 | Introduction + Lit Review sections | Drafted sections | arts-paper-writer → section |
| 7 | Methodology section | Methodology draft | arts-paper-writer → section |
| 8-9 | Analysis / Findings | Analysis draft | arts-paper-writer → section |
| 10 | Discussion + Conclusion | Discussion + Conclusion | arts-paper-writer → section |
| 11 | Abstract (bilingual) + title | TCI-ready abstract | arts-paper-writer → abstract |
| 12 | Internal review | Writing Quality Report | arts-paper-writer → WQC |
| 13 | Peer review simulation | Pre-submission review | arts-paper-reviewer → pre-submission |
| 14 | Revision | Revised manuscript | arts-paper-writer → revision |
| 15 | Final proofread + submission | Submitted manuscript | — |
```

**ปรับ timeline ตาม**:
- มี literature ครบแล้ว → ตัด Week 1-2
- มี analysis ครบแล้ว → ตัด Week 8-9
- ไม่มี deadline กด → ขยาย timeline ได้

### 4. Milestone Checklist

```markdown
# Milestone Checklist

## Pre-writing Phase
- [ ] RQ confirmed (FONER assessment ผ่าน)
- [ ] Literature Matrix สมบูรณ์ (≥15 sources, TCI ครบ)
- [ ] Theoretical Framework เลือกและ justify แล้ว
- [ ] Target journal เลือกแล้ว + อ่าน submission guidelines
- [ ] Paper structure เลือกแล้ว (A/B/C/D)
- [ ] Paper Plan Card confirmed

## Writing Phase
- [ ] Introduction drafted + confirmed
- [ ] Literature Review drafted + confirmed
- [ ] Methodology drafted + confirmed
- [ ] Analysis drafted + confirmed
- [ ] Discussion drafted + confirmed
- [ ] Conclusion drafted + confirmed

## Post-writing Phase
- [ ] Bilingual abstract aligned
- [ ] Writing Quality Check passed
- [ ] Pre-submission peer review completed
- [ ] Revision addressed
- [ ] TCI compliance verified
- [ ] References formatted correctly
- [ ] Figures/images at correct resolution
```

### 5. Risk Assessment

```markdown
# Risk Assessment

| ความเสี่ยง | ระดับ | แผนรับมือ |
|---------|------|---------|
| Literature ยังบาง | สูง/กลาง/ต่ำ | ใช้ arts-deep-research เพิ่มเติม |
| RQ ยังไม่ชัด | สูง | Socratic mode ก่อนเขียน |
| Theory ไม่ fit | กลาง | theory-focus mode ใน arts-paper-reviewer |
| ข้อมูล / analysis ไม่ครบ | สูง | ชะลอการเขียนจนกว่าจะพร้อม |
| เวลาไม่พอ | กลาง | ตัด optional sections, เน้น P1 ก่อน |
| ขาด cultural sensitivity | กลาง | เพิ่ม ethics consultation |
```
