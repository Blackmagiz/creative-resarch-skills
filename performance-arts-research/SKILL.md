## Part 1: Performance Studies Foundation

### Schechner's Broad Spectrum (Performance Studies)

Richard Schechner ขยายนิยาม "performance" ให้กว้างกว่า theatre:
- Theater (ละครเวที)
- Ritual (พิธีกรรม)
- Sport
- Play/Game
- Everyday life performance (Goffman)
- Politics (state performance)
- Healing & shamanic performance

→ ทำให้วิจัยรามเกียรติ์ลิเก, พิธีกรรมล้านนา, การแสดงพื้นบ้าน เป็น "performance" ทางวิชาการได้

### Key Concepts

**Restored Behavior (Schechner)**: Performance = "behavior twice-behaved" — ฝึกฝนซ้ำแล้วซ้ำเล่า

**Liminality (Turner)**: ขอบเขตระหว่าง "ปกติ" — performance อยู่ในพื้นที่ liminal

**Performativity (Butler, Austin)**: คำพูด/การกระทำที่ "do" สิ่งใดสิ่งหนึ่ง ไม่ใช่แค่ describe

**Embodiment**: ความรู้ที่ฝังในร่างกาย — สำคัญสำหรับ dance, traditional arts

### Performance Analysis Framework

วิเคราะห์การแสดงผ่าน 5 มิติ:

1. **Body & Voice** — การเคลื่อนไหว, gesture, vocal quality, breath
2. **Space & Time** — staging, blocking, rhythm, duration
3. **Object & Costume** — props, sets, costume, makeup
4. **Music & Sound** — score, soundscape, silence
5. **Audience & Reception** — relationship, response, context

## Part 2: Music Analysis Methods

### A. Western Tonal Analysis

**Roman Numeral Analysis**:
- ระบุ chord progressions
- Tonicization, modulation
- Cadence types

**Schenkerian Analysis** (Heinrich Schenker):
- ค้นหา "Ursatz" (fundamental structure)
- Foreground → Middleground → Background
- Reduction technique
- ใช้กับ tonal music เป็นหลัก (Bach-Brahms)

**Form Analysis**:
- Binary, ternary, sonata, rondo, theme & variations
- Phrase structure (Caplin)

### B. Set Theory (Atonal/Post-tonal)

ใช้สำหรับ Schoenberg, Webern, contemporary classical:
- Pitch-class sets
- Interval vectors
- Set-class identification (Forte names: 3-1, 4-z29, etc.)
- Twelve-tone analysis (matrix, row forms)

### C. Semiotic Music Analysis

(Nattiez, Tarasti, Hatten):
- Topics & topoi (เช่น pastoral, military, learned style)
- Markedness — what stands out
- Narrative analysis ใน instrumental music

### D. Spectromorphology (Smalley)

สำหรับ electroacoustic music, sound art:
- Spectral analysis (FFT)
- Morphological types (note, granular, texture, attack, decay)
- Spatial analysis

### E. Ethnomusicological Methods

(Merriam, Nettl, Rice, Feld):

**Three-part model (Merriam)**:
1. Concept — แนวคิดเกี่ยวกับเสียงในวัฒนธรรมนั้น
2. Behavior — พฤติกรรมที่เกี่ยวข้อง (การฝึก, การแสดง, การฟัง)
3. Sound — ตัวเสียง

**Cantometrics (Lomax)**: comparative coding system (controversial แต่ยังมีอิทธิพล)

**Musical event analysis (Stone)**: เน้นบริบทของ event มากกว่า music object

## Part 3: ดนตรีไทย & ดนตรีล้านนา

### ระบบดนตรีไทย

**ระบบเสียง (Tuning)**:
- 7-tone equidistant (โดยประมาณ — ไม่ใช่ Western 12-TET)
- ระบบ "เสียง" (โน้ต): โด, เร, มี, ฟา, ซอล, ลา, ที (ปรับให้เข้ากับการสอน)

**ทำนองหลัก**: ฉับ, สาธุการ, แขกบรเทศ, แสดงโขน etc.

**โครงสร้าง**:
- เพลงเดี่ยว, เพลงเรื่อง, เพลงเภท
- 3 ชั้น (สามชั้น, สองชั้น, ชั้นเดียว)
- ทาง (mode/key system)

**Notation**:
- ระบบไทยดั้งเดิม: ไม่มีโน้ตเขียน — ฝากท่องและสาธิต
- ระบบสมัยใหม่: 5-line staff ปรับใช้ + tablature สำหรับเครื่อง
- รูปแบบ "ทำนอง" บันทึกของพระเจนดุริยางค์, ม.ล.ปิ่น มาลากุล

### ดนตรีล้านนา

- ปี่ฆ้องคู่
- สะล้อ, ซึง
- เพลงตะโล้นโต้น, ดนตรีพื้นเมืองล้านนา
- ระบบแม่บท: ทางขับซอ ฯลฯ

### Critical Note สำหรับงานวิจัยดนตรีไทย

⚠️ **อย่าใช้ Western analysis straight** — Schenkerian, set theory ออกแบบมาสำหรับ Western tonal/atonal — ใช้กับดนตรีไทยอาจทำให้ misrepresent ระบบ

แนวทางที่เหมาะ:
1. เริ่มจาก emic perspective (ภายในวัฒนธรรม) — ครูเพลงไทยอธิบายอย่างไร?
2. ใช้คำศัพท์ไทยที่มีอยู่ (ทำนอง, ลูกตก, คำลักษณนาม)
3. ถ้าใช้ Western framework ต้อง reflect ความ fit/misfit

### นาฏศิลป์ไทย

**ระบบ "ท่ารำ" (mae bot)**:
- 12 ท่าหลัก (จับไว้, จับโบก, นาคา ฯลฯ)
- ผสมเป็น "เพลงรำ"
- Codified ทางสายโขน/ละคร/ระบำ

**Notation**:
- ดั้งเดิม: ฝากการสอนตัวต่อตัว + ตำราภาพประกอบ
- สมัยใหม่: photographic notation, Labanotation (ปรับใช้)

## Part 4: Dance/Movement Notation

### Labanotation (Kinetography Laban)

- ใช้กับนาฏศิลป์โลก
- บันทึก: body part, direction, level, duration, rhythm
- เหมาะกับ contemporary dance, ballet
- ปรับใช้กับนาฏศิลป์ไทยได้ แต่ขาด nuance ของ "ความอ่อนช้อย"

### Benesh Movement Notation (BMN)

- ใช้ใน Royal Ballet, Royal Academy of Dance
- เน้น classical ballet
- รองรับ pas de deux, ensemble

### Eshkol-Wachman Movement Notation (EWMN)

- คณิตศาสตร์เป็นแกน
- บันทึก movement ของ body part อย่างละเอียด
- ใช้ในการวิเคราะห์ animal behavior, robotics, dance

### LMA (Laban Movement Analysis)

ขยายจาก Labanotation:
- **Body** — what part moves
- **Effort** — how (weight, time, space, flow)
- **Shape** — body form changing
- **Space** — spatial pathways

## Part 5: Performance Ethnography

### ก่อนทำ fieldwork

1. **IRB approval** + community consultation
2. **Reciprocity plan** — return to community ในรูปแบบใด?
3. **Recording permissions** — ทุกคนใน frame ต้อง consent
4. **Cultural protocols** — โดยเฉพาะ sacred performance, ritual

### ระหว่าง fieldwork

**Three layers of documentation**:
1. **Audio/video recording** — primary record
2. **Field notes** — observations + reflections (เขียนวันเดียวกับเก็บข้อมูล)
3. **Interviews** — กับ performers, organizers, audiences

### Bi-musicality (Mantle Hood)

นักวิจัยควรเรียน performance ของวัฒนธรรมที่ศึกษา — ไม่ใช่แค่ analyze จากภายนอก
- เพิ่ม insider knowledge
- Reciprocity ทางความรู้
- ลด exoticization

### หลัง fieldwork

**Transcription strategies**:
- Etic transcription (Western notation) — สำหรับ comparative
- Emic transcription (system ของวัฒนธรรมนั้น) — สำหรับ accuracy
- Both — ดีที่สุด แต่ใช้เวลามาก

**Analysis layers**:
1. Sound/movement structures
2. Participants' meaning-making
3. Wider socio-cultural context

## Part 6: Performance Practice Research (Practice-based)

ดู `practice-based-research` skill ร่วม — แต่ specific สำหรับ performance:

### Documentation challenges

Performance เป็น **time-based & ephemeral** — แต่งานวิจัยต้องการ traceable evidence:

1. **Multi-camera video** — กล้องหลายมุมจับ ensemble
2. **Audio separate** — high-quality audio recording (ไม่พึ่ง camera mic)
3. **Score/notation** ถ้ามี
4. **Director's/Choreographer's notes** — staging diagrams
5. **Process journal** — rehearsal-by-rehearsal
6. **Audience response** — feedback forms, reception interviews
7. **Critical reflection** — written ขณะและหลังการแสดง

### Documentation Quality

- Video: minimum 1080p, 24-30fps; better 4K สำหรับ archive
- Audio: 24-bit 48kHz minimum
- Stable camera ที่ไม่ขวาง audience
- Multiple takes ถ้าเป็นไปได้
- Backup recording เสมอ

## Part 7: Common Research Designs

### A. Single-Work Analysis
- Deep analysis of one composition/performance/dance
- Multiple methodological lenses
- Original interpretation contribution

### B. Comparative Study
- 2-5 works/artists/traditions
- Common analytical framework
- Identify similarities/differences/dialogues

### C. Historical Study
- Trace development of style/genre/repertoire
- Archival research + score analysis
- Place in wider socio-cultural narrative

### D. Reception/Audience Study
- How is performance perceived?
- Mixed methods: surveys, interviews, ethnographic
- Cultural studies framework

### E. Pedagogy Research
- ดู `arts-education` (ถ้ามี skill เพิ่ม) — เน้น how is performance taught/learned
- เหมาะกับสาขา ดนตรีศึกษา, นาฏศิลป์ศึกษา

### F. Practice-as-Research
- Researcher-performer creates work
- Work + exegesis = thesis
- ดู `practice-based-research` skill

## Anti-patterns ในงานวิจัยการแสดง

🚫 **Score-only analysis** — วิเคราะห์แค่โน้ต โดยไม่ฟังการแสดงจริง
🚫 **Western framework imposition** — ใช้ Schenkerian วิเคราะห์ดนตรีไทยตรงๆ
🚫 **Author-centric** — focus แค่ composer/choreographer ละเลย performers
🚫 **Decontextualized recording** — ใช้ recording เดียวเป็น "the work" โดยไม่ระบุ performance/version
🚫 **Romantic exoticism** — บรรยายดนตรีพื้นบ้านในแบบ "บริสุทธิ์ ดั้งเดิม นานเกินกาล"
🚫 **Missing performers' agency** — ทำเหมือน performers แค่ "execute" ไม่มี creative interpretation

## Workflow Suggestions

```
Music Composition Analysis:
1. ฟังหลายครั้งโดยไม่จด — first impressions
2. Read score (ถ้ามี) — structural overview
3. Multiple recordings (ถ้ามี) — variants/interpretations
4. Choose method(s) ที่เหมาะ
5. Detailed analysis with annotations
6. Contextualize: composer, period, culture, function
7. Synthesis + interpretation
```

```
Performance Analysis:
1. Watch full performance (live หรือ recording)
2. Note immediate impressions
3. Re-watch with focus on each layer (body, space, time, sound, audience)
4. Identify key moments (turning points, climaxes)
5. Analyze using performance studies framework
6. Compare with other versions/performances
7. Synthesize
```

```
Ethnomusicological Field Study:
1. IRB + community approval
2. Pilot fieldwork — refine questions
3. Extended fieldwork (3-12 months ideal)
4. Transcribe & analyze in dialogue with community
5. Member checking — return findings to community
6. Write with reflexivity about positionality
7. Plan how findings benefit community
```
