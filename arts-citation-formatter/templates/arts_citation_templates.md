# Arts Citation Templates — Quick Reference

## Artwork (Original)

```
APA 7:
Artist, A. (Year). Title of work [Medium]. Institution, City. URL

Chicago Notes:
Artist Name, Title of Work, Year, medium, dimensions, Institution, City.

Caption under image:
Artist Name, Title, Year. Medium, W × H cm. Collection, Institution, City.
[Photo credit if applicable]
```

## Exhibition Catalog

```
APA 7:
Editor, E. E. (Ed.). (Year). Title of exhibition [Exhibition catalog]. Museum.

Chicago:
Editor Name, ed. Title of Exhibition. Exhibition catalog. City: Museum, Year.
```

## Artwork in Catalog

```
Chicago:
Author. "Essay Title." In Title of Exhibition, edited by Editor, pp. City: Museum, Year.
```

## Performance (Live)

```
Chicago:
Performer(s). Title of Work, by Composer/Choreographer. Performed at Venue, City, Date.

TCI-adapted:
ผู้แสดง. ชื่อผลงาน, โดย ผู้ประพันธ์/นักออกแบบท่า. แสดง ณ สถานที่, เมือง, วันที่.
```

## Oral Interview (Unpublished)

```
Chicago:
Interviewee Name. Year. Interview by Interviewer Name. Date. Location/Method. 
[recording in possession of interviewer]

TCI-adapted:
ชื่อผู้ให้สัมภาษณ์. (ปี). สัมภาษณ์โดย ชื่อผู้สัมภาษณ์. วันที่. สถานที่. 
[บันทึกในความครอบครองของผู้สัมภาษณ์]
```

## Archival Document

```
Chicago:
[Document description], [Date], [Collection + identifier], [Archive], [City].

Example:
สัญญาซื้อขายที่ดิน, พ.ศ. 2455, หจช.ชม. 12/4, หอจดหมายเหตุแห่งชาติ เฉลิมพระเกียรติฯ เชียงใหม่.
```

## TCI Thai Journal Article

```
ชื่อ นามสกุล. (พ.ศ.). ชื่อบทความ. ชื่อวารสาร, ปีที่(ฉบับที่), หน้าเริ่ม-หน้าสิ้นสุด.

Example:
สาคร เลิศคุณวุฒิ. (2563). จิตรกรรมฝาผนังล้านนา. วารสารวิชาการศิลปะ, 12(2), 45-67.
```

## Film

```
APA 7:
Director, D. (Director). (Year). Title [Film]. Studio.

Chicago:
Director Name (director). Title. City: Studio, Year.

Thai film:
ผู้กำกับ ชื่อ (ผู้กำกับ). (พ.ศ.). ชื่อภาพยนตร์ [ภาพยนตร์]. บริษัทผู้ผลิต.
```

## Digital / NFT Artwork

```
Artist Name, Title, Year, medium/format (e.g., AI-generated video / NFT).
URL (accessed Date).
```

## Music Score

```
Chicago:
Composer, First Last. Title of Work. Edited by First Last. City: Publisher, Year.

Thai traditional music (ไม่มี score):
Note methodology: "วิเคราะห์จากการฟังการบันทึกเสียงโดย [ชื่อนักดนตรี], 
บันทึกเมื่อ [ปี], เก็บรักษาที่ [แหล่ง]"
```
