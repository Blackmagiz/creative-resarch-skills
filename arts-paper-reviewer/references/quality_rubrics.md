# Quality Rubrics (0-10 Scale) สำหรับ Arts Research

## หลักการ

คะแนน 0-10 ต้องอ้างอิงจาก evidence ในบทความเสมอ ห้ามให้คะแนนโดยสัญชาตญาณ

## 7 มิติการประเมิน

### มิติที่ 1: Originality (ความเป็นต้นฉบับ)
| คะแนน | เกณฑ์ |
|-------|-------|
| 9-10 | ต้นฉบับสูงมาก — topic/method/lens ใหม่ในวงการ, เปิดมุมมองใหม่ |
| 7-8 | ต้นฉบับดี — มี contribution ชัดเจน แต่ไม่ก้าวกระโดด |
| 5-6 | ต้นฉบับปานกลาง — extend งานเดิมได้บ้าง แต่ไม่ใหม่มาก |
| 3-4 | ต้นฉบับน้อย — ส่วนใหญ่ replication หรือ summary |
| 1-2 | ไม่มีต้นฉบับ — replicate โดยไม่เพิ่ม value |
| 0 | Plagiarism หรือ duplicate submission |

### มิติที่ 2: Significance (ความสำคัญ)
| คะแนน | เกณฑ์ |
|-------|-------|
| 9-10 | ผลกระทบสูงต่อสาขาและ/หรือสังคมในวงกว้าง |
| 7-8 | สำคัญต่อสาขา มี theoretical หรือ practical implication ชัดเจน |
| 5-6 | มี implication แต่ขอบเขตจำกัด |
| 3-4 | ความสำคัญไม่ชัด — ผู้อ่านต้องตีความเอง |
| 1-2 | ไม่ชี้ความสำคัญเลย |

### มิติที่ 3: Methodology (วิธีวิจัย)
| คะแนน | เกณฑ์ |
|-------|-------|
| 9-10 | Method เหมาะสมอย่างยิ่ง, rigor สูง, limitations ชัดเจน |
| 7-8 | Method เหมาะสม, ปัญหาเล็กน้อยที่แก้ได้ |
| 5-6 | Method ใช้ได้แต่มีจุดอ่อนที่ต้องชี้แจง |
| 3-4 | Method มีปัญหาที่กระทบความเชื่อถือได้ |
| 1-2 | Method ไม่เหมาะสมกับ RQ |
| 0 | ไม่มี methodology อธิบาย หรือ data fabricated |

### มิติที่ 4: Theoretical Engagement (การ engage กับทฤษฎี)
| คะแนน | เกณฑ์ |
|-------|-------|
| 9-10 | ใช้ theory อย่างลึกซึ้ง contribute ต่อ theoretical discourse |
| 7-8 | ใช้ theory อย่างถูกต้อง เชื่อมกับ argument หลักได้ดี |
| 5-6 | ใช้ theory ได้แต่บางส่วน shallow หรือ name-dropping |
| 3-4 | Theory drop — ชื่อทฤษฎีปรากฏแต่ไม่ได้ทำงานจริง |
| 1-2 | ไม่มี theoretical framework เลย |

### มิติที่ 5: Literature Review Quality (คุณภาพวรรณกรรม)
| คะแนน | เกณฑ์ |
|-------|-------|
| 9-10 | ครอบคลุม, สังเคราะห์ดี, gap ชัดเจน |
| 7-8 | ครอบคลุมงานสำคัญ, synthesis ดี |
| 5-6 | ครอบคลุมพอสมควร แต่ขาดบางส่วน |
| 3-4 | Annotated bibliography style, ไม่มี synthesis จริง |
| 1-2 | ขาด canonical works, หรือ lit review น้อยมาก |

### มิติที่ 6: Writing Quality (คุณภาพการเขียน)
| คะแนน | เกณฑ์ |
|-------|-------|
| 9-10 | ชัดเจน, precise, academic register ดี, argument ไหลลื่น |
| 7-8 | ดี, แก้เล็กน้อย |
| 5-6 | ใช้ได้แต่มีความคลุมเครือบางส่วน |
| 3-4 | ยากอ่าน, argument ไม่ชัด, ภาษาไม่ดี |
| 1-2 | ต้อง language editing ก่อนพิจารณา |

### มิติที่ 7: Citation Quality (คุณภาพการอ้างอิง)
| คะแนน | เกณฑ์ |
|-------|-------|
| 9-10 | References ครบ, รูปแบบสม่ำเสมอ, ตรวจสอบได้ทุกรายการ |
| 7-8 | ดี แต่มีข้อผิดพลาดเล็กน้อย |
| 5-6 | มีข้อผิดพลาดปานกลาง, format ไม่สม่ำเสมอ |
| 3-4 | References หลายรายการที่ตรวจสอบแล้วไม่ถูกต้อง |
| 1-2 | References ส่วนใหญ่ไม่ถูกต้อง หรือ AI-generated |
| 0 | References ปลอมทั้งหมด |

## Decision Mapping

| Overall Average | คำแนะนำ |
|----------------|---------|
| 8.0-10.0 | Accept |
| 6.5-7.9 | Minor Revision |
| 4.5-6.4 | Major Revision |
| < 4.5 | Reject |
| มิติใดได้ 0 | Reject อัตโนมัติ |

**หมายเหตุ**: DA CRITICAL issue override เกณฑ์ข้างต้น — ถ้า DA CRITICAL → ไม่ Accept ไม่ว่า average จะเป็นเท่าไร
