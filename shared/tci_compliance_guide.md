# TCI Compliance Guide

*คู่มือนี้ครอบคลุมทุกข้อกำหนดของ Thai-Journal Citation Index สำหรับ submission*

---

## TCI คืออะไร

Thai-Journal Citation Index (TCI) คือฐานข้อมูลดัชนีการอ้างอิงวารสารวิชาการไทย บริหารโดยมหาวิทยาลัยเทคโนโลยีพระจอมเกล้าธนบุรี แบ่งเป็น:

| Tier | ลักษณะ | ตัวอย่างวารสาร |
|------|--------|--------------|
| TCI 1 | คุณภาพสูง, peer-reviewed เข้มข้น | วารสารวิชาการศิลปะ การออกแบบ ฯ |
| TCI 2 | คุณภาพดี, peer-reviewed | วารสารระดับมหาวิทยาลัย |

**หมายเหตุ**: TCI กำหนด requirements พื้นฐาน แต่แต่ละวารสารอาจมีข้อกำหนดเพิ่มเติม → ตรวจ journal-specific guidelines เสมอ

---

## Mandatory Requirements (ทุก TCI journal)

### 1. Abstract — Bilingual (บังคับ)

| ภาษา | ความยาว | คุณภาพ |
|------|---------|--------|
| ภาษาไทย | 200-300 คำ | ต้องเขียนโดยผู้เชี่ยวชาญภาษา |
| ภาษาอังกฤษ | 200-300 คำ | คุณภาพดีเท่ากับภาษาไทย |

**⚠️ Critical**: เนื้อหาต้องตรงกันทั้งสองภาษา — ห้าม add/omit ข้อมูลต่างกัน

### 2. Keywords — Bilingual (บังคับ)

| ภาษา | จำนวน | รูปแบบ |
|------|------|--------|
| ภาษาไทย | 5-7 คำ/วลี | คั่นด้วยจุลภาค |
| ภาษาอังกฤษ | 5-7 คำ/วลี | คั่นด้วยจุลภาค |

**Tips การเลือก keywords**:
- ไม่ซ้ำกับคำในชื่อเรื่อง (ส่วนใหญ่)
- Specific เพียงพอให้ค้นหาเจอใน databases
- รวม: topic, method, geographical context, period/era (ถ้าเกี่ยวข้อง)

### 3. Author Information (บังคับ)

```
สิ่งที่ต้องมีสำหรับทุกผู้เขียน:
□ ชื่อ-นามสกุล ภาษาไทย
□ ชื่อ-นามสกุล ภาษาอังกฤษ (romanized ถูกต้อง)
□ สังกัด (Affiliation) — ระดับ: หน่วยงาน/สาขา/คณะ/มหาวิทยาลัย/ประเทศ
□ E-mail address (อย่างน้อย corresponding author)
□ ระบุ corresponding author ชัดเจน
```

### 4. Conflict of Interest Statement (บังคับ)

```
รูปแบบ (เลือกตามกรณี):

กรณีไม่มี:
"ผู้เขียนขอรับรองว่าไม่มีผลประโยชน์ทับซ้อนในการวิจัยนี้"
"The authors declare no conflict of interest."

กรณีมี:
"[ชื่อผู้เขียน] ได้รับทุนวิจัยจาก [แหล่งทุน] ซึ่งอาจมีผลประโยชน์เกี่ยวข้องกับ..."
"[Author] received funding from [source], which may have an interest in..."
```

### 5. AI Use Disclosure (บังคับ — ถ้าใช้ AI)

```
รูปแบบ:

"บทความนี้ได้รับความช่วยเหลือจาก [ชื่อ AI tool และ version] สำหรับ 
[งานที่ใช้ เช่น การตรวจสอบไวยากรณ์ / การค้นหาวรรณกรรม / การจัดรูปแบบ]
การออกแบบวิจัย การวิเคราะห์ การตีความ และการเขียนทั้งหมดดำเนินการโดยผู้เขียน
การอ้างอิงและข้อมูลทั้งหมดได้รับการตรวจสอบจากแหล่งต้นฉบับ"

"This manuscript utilized [AI tool name and version] for [specific tasks].
All research design, analysis, interpretation, and final writing decisions
were made by the author(s). All references and data have been independently
verified against original sources."

กรณีไม่ใช้: ระบุ "ไม่มีการใช้ AI ในการเขียนบทความนี้" / "No AI tools were used."
```

### 6. References Format

ตรวจสอบ journal-specific style guide — TCI ไม่ได้กำหนด style เดียว

**Style ที่พบบ่อยใน TCI arts journals**:
- APA 7th edition
- Chicago 17th edition (author-date)
- วารสารบางแห่งมี in-house style

**ตรวจสอบ**: วารสารที่ target → ดูตัวอย่าง references ใน published article

### 7. Figure/Image Requirements

| ข้อกำหนด | Standard |
|---------|---------|
| Resolution | ≥ 300 DPI สำหรับ print |
| Format | TIFF, JPEG, PNG (ตามที่ journal ระบุ) |
| Caption | ครบถ้วน: ชื่อผลงาน, ปี, medium, ขนาด, collection, credit |
| Copyright | ต้องมี permission letter สำหรับงานที่มีลิขสิทธิ์ |
| Numbering | ภาพที่ 1, 2, 3... หรือ Figure 1, 2, 3... (ตาม style) |

## Submission Package Checklist

```
□ Manuscript ครบทุก section
□ Abstract ภาษาไทย (200-300 คำ) ✓
□ Abstract ภาษาอังกฤษ (200-300 คำ, aligned) ✓
□ Keywords ภาษาไทย (5-7) ✓
□ Keywords ภาษาอังกฤษ (5-7) ✓
□ ชื่อ-นามสกุลผู้เขียนทั้งสองภาษา ✓
□ Affiliation ครบทุกผู้เขียน ✓
□ E-mail + corresponding author ✓
□ Conflict of interest statement ✓
□ AI disclosure statement ✓
□ References — format สอดคล้องกับ journal style guide ✓
□ Figures ≥ 300 DPI + captions ครบ ✓
□ Copyright permission (ถ้าจำเป็น) ✓
□ Cover letter (บางวารสารบังคับ) ✓
□ ตรวจสอบ journal word limit ✓
□ ตรวจสอบ journal format requirements (margins, font, spacing) ✓
□ Blind review: ลบข้อมูล author จาก manuscript ถ้า double-blind ✓
```
