# Failure Paths — Practice-Based Research

| # | ชื่อ | Trigger | ผลกระทบ | Recovery |
|---|-----|---------|---------|---------|
| F1 | Practice ≠ Research | ผู้ใช้บรรยาย creative process แต่ไม่มี RQ | งานเป็นแค่ portfolio ไม่ใช่ research | หยุด → ถาม "ผลงานนี้กำลังตอบคำถามอะไร?" → arts-deep-research Socratic |
| F2 | Knowledge Contribution Absent | ไม่สามารถระบุได้ว่า practice contribute อะไรใหม่ | ไม่ผ่านเกณฑ์ academic research | หยุด → ทำ "knowledge contribution mapping" ก่อนเขียน |
| F3 | Structure Mismatch | ใช้ traditional paper format กับ practice-based work | ผลงานสร้างสรรค์ถูก marginalize | switch to Exegesis format → arts-paper-writer → exegesis mode |
| F4 | Reflexivity Missing | ไม่มี researcher positionality statement | reviewer จะตั้งคำถามเรื่อง bias | เพิ่ม reflexivity section ใน methodology |
| F5 | Documentation Insufficient | มีแต่ final work ไม่มี process documentation | ไม่สามารถ show "knowledge from practice" | retrospective documentation + process journal |
| F6 | Ethics Gap | ใช้ community knowledge/materials โดยไม่มี consent | ปัญหา cultural appropriation | หยุด → cultural consultation → attribution ที่ถูกต้อง |
| F7 | Practice-Theory Disconnect | ทฤษฎีที่เลือกไม่สอดคล้องกับ medium/practice | exegesis อ่อนแอ | arts-paper-reviewer → creative-component mode |
| F8 | Over-theorized Exegesis | exegesis เต็มไปด้วยทฤษฎีแต่ไม่ describe ผลงาน | reader ไม่เข้าใจผลงานจริง | เพิ่ม "The Work" section ด้วย concrete description + documentation |

---

## Detailed Recovery: F1 — Practice ≠ Research

**Detection signals**:
- ผู้ใช้พูดถึง "ฉันสร้างงาน X" แต่ไม่มีคำถามที่งาน X ตอบ
- Description บอกว่า "ทำ" อะไร แต่ไม่บอกว่า "ค้นหา" อะไร

**Recovery questions**:
```
1. "ผลงานนี้กำลัง explore คำถามอะไร?"
2. "หลังจากสร้างผลงาน คุณรู้อะไรที่ก่อนทำไม่รู้?"
3. "ทำไมการสร้างผลงานนี้ถึงเป็นวิธีที่ดีที่สุดในการตอบคำถามนั้น?"
```

**ถ้าผู้ใช้ยังไม่สามารถตอบได้**: แนะนำ arts-deep-research → Socratic mode ก่อน

## Detailed Recovery: F2 — Knowledge Contribution Absent

**Knowledge Contribution Mapping Exercise**:

ให้ผู้ใช้ตอบ:
```
งาน creative ของฉัน...
□ สำรวจ material ที่ยังไม่มีใครใช้ใน context นี้ (knowledge IN)
□ ค้นพบ process/method ใหม่ระหว่างทำ (knowledge FROM)  
□ ท้าทาย/เสริม discourse เกี่ยวกับ [topic] (knowledge ABOUT)
□ พัฒนา methodology ที่ artist คนอื่นนำไปใช้ได้
□ อื่นๆ: ___
```

**ถ้ายังตอบไม่ได้**: อาจเป็น practice-led (not practice-based) → ปรับ approach

---

## Detailed Recovery: F6 — Ethics Gap

**สำหรับงานที่ involve ชุมชน/วัฒนธรรมเฉพาะ**:

```
Checklist:
□ ได้รับ informed consent จาก community members ไหม?
□ มี attribution ที่ถูกต้องสำหรับ knowledge/materials ที่ใช้?
□ community มี benefit sharing ไหม (ถ้าผลงานถูก commercialize)?
□ มีการ consult กับ cultural authority ของชุมชน?
□ ถ้าเป็นงานล้านนา/ชนเผ่า: ได้ติดต่อ SAC หรือ cultural custodians?
```

**ถ้าขาด**: หยุดกระบวนการ → cultural consultation → retrospective consent (ถ้าเป็นไปได้) → หรือ scope ใหม่
