# Process Journal Template

*บันทึกทุกครั้งที่ทำงานสร้างสรรค์ — ใช้เป็น primary evidence สำหรับ exegesis*

---

## Entry Format

```markdown
## บันทึกวันที่: [DD/MM/YYYY]
**Session**: [เลขที่ session / ชื่อ phase]
**Duration**: [กี่ชั่วโมง]
**Location**: [studio / venue / field]

### สิ่งที่ทำวันนี้
[บรรยาย activities]

### Material/Technique Decisions
| ตัดสินใจเรื่อง | ตัวเลือก | เลือก | เหตุผล |
|------------|--------|------|------|
| | | | |

### สิ่งที่ได้ผล ✅
[บรรยาย]

### สิ่งที่ไม่ได้ผล ❌ และเหตุผล
[บรรยาย — ซื่อสัตย์]

### การค้นพบ / Insight
[สิ่งที่ไม่ได้คาดไว้ หรือเปลี่ยน understanding]

### เชื่อมกับ Theory/Literature
[ถ้ามี — อะไรที่ที่อ่านมาช่วย explain สิ่งที่ค้นพบ]

### คำถามที่เกิดขึ้น
[คำถามที่ยังไม่มีคำตอบ — สำหรับ future investigation]

### Reflexive Notes
[ความคิด/ความรู้สึกของผู้วิจัยในฐานะ artist-researcher]

### Documentation Checklist วันนี้
□ ภาพถ่าย process
□ บันทึกวิดีโอ (ถ้าจำเป็น)
□ เก็บ material samples
□ อัปเดต iteration log
```
